# Agent Handoff Directory

[English](README.md) | [简体中文](README.zh-CN.md)

This directory contains project maps, current tasks, and verification logs designed for AI Coding Agents.

## Files Layout
- `packaged-context.xml`: Unified XML context bundle (recommended entry point).
- `code-map.md`: Project static directory mapping, entry points, and module dependency graph.
- `project.md`: Overall project metadata, architecture, and technology stack.
- `current-task.md`: Active task roadmap and state (preserved incrementally).
- `agent-handoff.md`: Primary handoff notes, workflow anchors, and next session focus.
- `changed-files.md`: Automatically extracted summary of modified files and platform APIs.
- `decisions.md`: Engineering decision logs.
- `known-issues.md`: Traps, environment constraints, and blockers.
- `validation.md`: Test scripts and execution output verification logs.
- `next-agent-prompt.md`: Read-first instructions prompt for the incoming agent.
