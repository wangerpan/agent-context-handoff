# AI Context Directory

This directory contains current tasks and environment status logs designed for AI Coding Agents.

## Files Layout
- `project.md`: Overall project metadata, architecture, and technology stack.
- `current-task.md`: Active task roadmap and state.
- `agent-handoff.md`: Primary handoff file generated by the previous developer.
- `changed-files.md`: Automatically extracted summary of modified files.
- `decisions.md`: Engineering decision logs.
- `known-issues.md`: Traps, environment constraints, and blockers.
- `validation.md`: Test scripts and execution output verification logs.
- `next-agent-prompt.md`: Read-first instructions prompt for the incoming agent.
