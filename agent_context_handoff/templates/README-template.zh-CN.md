# AI 上下文目录

本目录存储了为 AI Coding Agent 准备的项目上下文、状态记录和交接文档。

## 文件说明
- `project.zh-CN.md`: 项目的整体背景、架构和技术栈。
- `current-task.zh-CN.md`: 当前正在执行的任务路径和状态。
- `agent-handoff.zh-CN.md`: 上一个开发 Agent 留下的核心交接文档。
- `changed-files.zh-CN.md`: 自动抽取的代码变更文件摘要。
- `decisions.zh-CN.md`: 项目关键技术决策记录。
- `known-issues.zh-CN.md`: 踩坑记录、环境限制和已知阻塞点。
- `validation.zh-CN.md`: 验证测试命令及执行日志。
- `next-agent-prompt.zh-CN.md`: 接手 Agent 的引导提示词。
