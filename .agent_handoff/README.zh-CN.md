# Agent 交接上下文目录

[English](README.md) | [简体中文](README.zh-CN.md)

本目录存储了为 AI Coding Agent 准备的项目地图、状态记录和交接文档。

## 文件说明
- `packaged-context.xml` / `packaged-context.zh-CN.xml`: 统一打包的 XML 上下文（推荐接手入口）。
- `code-map.zh-CN.md` / `code-map.md`: 项目静态目录映射、核心入口定义与 Mermaid 依赖拓扑。
- `project.zh-CN.md` / `project.md`: 项目的整体背景、架构和技术栈。
- `current-task.zh-CN.md` / `current-task.md`: 当前正在执行的任务路径和状态（支持增量保留）。
- `agent-handoff.zh-CN.md` / `agent-handoff.md`: 核心交接引导、业务流路径锚点与下轮焦点。
- `changed-files.zh-CN.md` / `changed-files.md`: 自动抽取的代码变更文件摘要与平台 API。
- `decisions.zh-CN.md` / `decisions.md`: 项目关键技术决策记录。
- `known-issues.zh-CN.md` / `known-issues.md`: 踩坑记录、环境限制和已知阻塞点。
- `validation.zh-CN.md` / `validation.md`: 验证测试命令及执行日志。
- `next-agent-prompt.zh-CN.md` / `next-agent-prompt.md`: 接手 Agent 的引导提示词。
